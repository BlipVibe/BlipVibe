# Equip transitions — painted art for the skin-equip animations

When someone equips a full skin, the app plays an animation themed to that skin (js/fullskins.js `equipTransition`).
Some pieces are still drawn by code (soft circles, gradients). Replace them with PAINTED art that matches each skin's
approved concept and existing kit (open the kit folders listed to match style exactly).

Rules: transparent PNG with real alpha outside every shape, no text, no letters, no people/avatars, no logos.
Crisp, high-res, each piece drawn WHOLE (not cropped at the edges). Save each set into the folder given, exact names.
Finish with a contact sheet `_sheet.png` in each folder.
