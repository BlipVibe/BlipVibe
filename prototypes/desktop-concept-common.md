# Full skins on DESKTOP — common brief (read with the skin's own brief)

BlipVibe is a social app. Its "full skins" repaint every screen with generated art. Each skin is already built and
approved FOR PHONES. Now paint how the SAME skin looks in a DESKTOP web browser (blipvibe.com), 1440 px wide.
OWNER: "we should NOT just use the same template for all of them." The Scrapbook desktop (top bar → cover band →
three columns) is taken. Do NOT reuse that skeleton. Each skin gets its OWN STRUCTURE: where the navigation lives
(top, vertical rail, bottom taskbar, hanging ribbons…), how the profile/cover is presented, how many columns and how
they are shaped (a book spread, a stage, a manga panel grid, overlapping windows…). Follow the composition in the
skin brief; it was chosen so no two skins share a layout. Same FEATURES everywhere, different ARRANGEMENT.
Also (owner): EXACTLY as cluttered and rich as the phone concepts — props, ornaments, ephemera everywhere, not calm.

## Owner rules
- Desktop is the same world as the skin's phone version: same art, materials, ornaments, icons, fonts, palette,
  props. Read the skin's approved phone concept sheets first and reuse their motifs exactly.
- NEVER the plain default website layout (three white columns with a bit of skin art). The whole browser window is
  the skin's own WORLD, composed for a wide screen. Each skin must be laid out in its OWN way, so the skins look
  distinctly different from each other on desktop (the skin brief suggests a composition).
- Every panel, row, button, field, pill, tab, bar and bubble is painted art in the skin's material, never flat CSS.
  Ornament on rims/corners, calm centres where text sits. Text readable, inside its box.
- Nothing stretched: art is painted for desktop size (wide headers, sidebars, wide panels).
- Photos are never cropped; frames hug the photo. Profile picture sits IN FRONT of the cover frames.
- Liked / disliked visibly different (solid filled icon in the skin's accent).

## Output
Each screen = ONE landscape image of a desktop browser viewport, 1536x960, no browser chrome, no phone frames.
Paint each screen as its own image generation. Real readable English text exactly as given. Realistic placeholder
