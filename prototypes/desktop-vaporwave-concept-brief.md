Look: 1995 desktop OS + 80s synthwave. RETRO = grey bevel windows, navy title bars with _ □ × buttons, pixel icons,
Start taskbar, marble busts, palm trees, neon grid sunset, pink/cyan. MODERN = same world as a sleek present-day OS:
frosted rounded windows, floating dock, more BLUE. Dark modes = the night versions of each. No Windows/Apple logos:
the Start button uses a pixel palm-sunset emblem.
Desktop STRUCTURE (unique to this skin): a REAL 1995 DESKTOP OS. No app top bar: the synthwave wallpaper
(grid sunset, palms, marble bust) fills the screen, desktop ICONS (pixel icons with labels: Home, Groups, Skins,
Network, Saved, Messages, Notifications) run down the LEFT edge, and the TASKBAR runs along the BOTTOM: Start button
(pixel palm-sunset emblem), open-window buttons, a search box, music note, coins, avatar and clock in the tray, the
rendition switch as a tray icon. The app's pages are OVERLAPPING WINDOWS with grey bevels, navy title bars and _ □ ×
buttons: Home = "Feed.exe" big window in the middle, "Profile.exe" window top-left with the 4 cover photos as VHS
tape windows and the round photo, "Quests.exe" small window, "Buddies" (people) window, a sticky-note style coin goal.
MODERN = the same as a present-day OS: frosted rounded windows, a floating DOCK at the bottom instead of the taskbar,
a menu bar at the top. Dark modes are the night versions.
Cover photos: 4 (timeline frames). Include on retro Home: nothing else open; on retro Notifications: the START MENU
open from the taskbar (menu items: Home, Groups, Skins, Network, Messages, Settings, Screensaver, Shut Down) instead
of the search dropdown, and the search dropdown on Messages.
